## ☁️ AWS SimuLearn: Cloud Computing Essentials

### 📖 Overview
The city's web portal team wants to improve the reliability of its beach wave-size prediction webpage. To address this challenge, this lab explored AWS Cloud computing fundamentals and how cloud-based services can provide reliable and accessible web hosting solutions. Activities included identifying the characteristics of the AWS Cloud environment, exploring the core benefits of AWS products and services, comparing AWS Cloud infrastructure with traditional on-premises infrastructure, and deploying a static webpage using Amazon Simple Storage Service (Amazon S3). These exercises provided practical experience in cloud solution design, storage configuration, and static website hosting while demonstrating how AWS services can support real-world business requirements.

### 🛠️ AWS Cloud Components
| Services, Concepts & Features | Description |
|-------------------------------|-------------|
| Amazon Web Services (AWS) | Cloud computing platform providing on-demand computing, storage, and infrastructure services. |
| Amazon Simple Storage Service (Amazon S3) | Object storage service used to store and host static website files. |
| Amazon S3 Bucket | Storage container used to organize and manage website objects and files. |
| S3 Static Website Hosting | Feature that allows static websites to be hosted directly from an S3 bucket. |
| Bucket Policies | JSON-based policies that define access permissions for S3 buckets and their objects. |
| Index Document | Default webpage displayed when visitors access the static website endpoint. |
| Object Permissions | Access controls that determine whether users can retrieve stored objects. |
| AWS Management Console | Web-based interface used to configure and manage AWS services. |
| Cloud Computing | Delivery of computing resources and services over the internet. |
| On-Premises Infrastructure | Traditional IT infrastructure hosted and maintained within an organization's physical environment. |
