## ☁️ AWS SimuLearn: Cloud First Steps

### 📖 Overview
An island stabilization team wants to improve the reliability and availability of its computational infrastructure to support critical stabilization operations. To address this challenge, this lab explored Amazon Web Services (AWS) cloud computing and the use of Amazon Elastic Compute Cloud (Amazon EC2) to deploy reliable and fault-tolerant computing resources. Activities included evaluating the customer's infrastructure requirements, designing an appropriate cloud solution, deploying EC2 instances within multiple Availability Zones in the same AWS Region, and exploring how distributing compute resources across Availability Zones improves application availability and resilience. These exercises provided practical experience in cloud solution design, EC2 instance deployment, infrastructure configuration, and high-availability architecture while demonstrating how AWS services can support critical business operations.

### 🛠️ AWS Cloud Components
| Services, Concepts & Features | Description |
|-------------------------------|-------------|
| Amazon Web Services (AWS) | Cloud computing platform providing on-demand computing, storage, networking, and infrastructure services. |
| Amazon Elastic Compute Cloud (Amazon EC2) | AWS service that provides scalable virtual servers for running applications and computational workloads. |
| EC2 Instances | Virtual computing resources used to run applications and computational modules in the AWS Cloud. |
| AWS Regions | Geographical locations containing multiple isolated Availability Zones where AWS infrastructure is deployed. |
| Availability Zones (AZs) | Isolated locations within an AWS Region that provide independent infrastructure for improving application availability and resilience. |
| Multi-AZ Deployment | Architecture that distributes resources across multiple Availability Zones to improve availability and fault tolerance. |
| High Availability | Infrastructure design approach that minimizes downtime and maintains service accessibility. |
| Fault Tolerance | Ability of a system to continue operating when individual infrastructure components experience failures. |
| AWS Management Console | Web-based interface used to create, configure, and manage AWS resources. |
| Cloud Infrastructure | Computing resources and services delivered through cloud-based environments. |
